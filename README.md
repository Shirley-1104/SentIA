# SentIA 💜

## Descripción
SentIA es una plataforma web de orientación vocacional inteligente diseñada para ayudar a los usuarios a descubrir posibles caminos profesionales según sus intereses, habilidades y características emocionales.

El sistema realiza un test interactivo con preguntas dinámicas y genera resultados personalizados mostrando las carreras con mayor compatibilidad, perfiles detectados y recomendaciones académicas.

---

## Características
✅ Test dinámico con preguntas condicionales  
✅ Resultados personalizados  
✅ Top 3 carreras con mayor compatibilidad  
✅ Perfil emocional detectado  
✅ Habilidades identificadas  
✅ Campo laboral asociado  
✅ Universidades recomendadas  
✅ Diseño responsive e interactivo

## Instalación

Para ejecutar SentIA de manera local, siga los siguientes pasos.

### Requisitos previos

Antes de comenzar, es necesario tener instalado:

- Git
- Node.js
- npm
- Un navegador web
- Visual Studio Code (recomendado)

### 1. Clonar el repositorio
Desde una terminal, ejecute:

```bash
git clone https://github.com/Shirley-1104/SentIA.git 

### 2. Ingresar a la carpeta del proyecto: 
```bash
cd SentIA

### 3. Abrir el proyecto:
Abrir la carpeta de SentIA en VS Code

### 4. Ejecutar el proyecto localmente
Desde la carpeta raíz del proyecto, ejecute:

```bash
npx live-server

El servidor local se iniciará y el proyecto estará disponible en:
http://127.0.0.1:8080

### 5. Acceder al proyecto
Abra la dirección indicada en el navegador para acceder a SentIA y utilizar sus diferentes funcionalidades.
